# Personal Intelligence Brief｜2026-09-16

## EvenUp重构人身伤害案件文档生成流程

- 案件通常包含1000页以上医疗、账单和警察报告材料。
- 系统先分类、抽取事实、去重并绑定来源页，再开始起草。
- 复杂推理模型制定法律论证蓝图，较低成本模型负责规模化章节生成。
- 公司称起草时间由8—15小时降至约30分钟，某律所清除了45天积压。

**判断：** 案例显示，AI价值主要来自结构化事实、来源绑定、按风险选择模型和人工最终负责，而不是直接让单一大模型生成法律文档。效率和业务结果数字均来自企业或供应商案例，缺少独立质量审计、长期风险和成本数据。

## Carvana将Slack生产告警接入Claude Tag研发运维闭环

- Claude Tag可从生产告警开始调查并定位负责团队。
- 零售科学团队可让Agent从根因分析继续创建Pull Request。
- 团队为不同身份配置不同数据访问范围。
- 零售科学告警量下降56%，批发平台获取答案时间缩短65%。

**判断：** 这是一个将Agent嵌入既有团队协作工具、并通过权限分片和人工审核形成多人可观察生产闭环的案例。它展示了从告警到修复的工作流重构，但效果数据缺少绝对基线、样本规模和独立验证。

## Pictet在风险与数据驻留边界内分阶段推广Claude Code

- Pictet管理约8000亿瑞士法郎资产，技术部门约1500人。
- 约700人获得Claude Code和Claude Cowork访问权限。
- 通过25场实践工作坊培训超过500人。
- 部分用例必须运行在瑞士，数据不得持久化用于模型训练。

**判断：** 案例表明，金融机构规模化采用Agent依赖风险框架适配、数据边界、权限控制、分阶段推广和实战培训的共同设计，而不仅是模型性能。生产效率和质量结果仍缺少独立审计、成本投入和长期稳定性数据。
